# E-commerce Website QA Testing Project

## 1. Project Overview
This project focuses on testing an e-commerce website to identify functional issues and verify that its features work as expected.

## 2. Project Objectives
- Understand manual software testing.
- Create and execute test cases.
- Identify and document bugs.
- Perform positive and negative testing.
- Maintain proper testing documentation.

## 3. Scope of Testing
The following features will be tested:
- User login
- Product search
- Product selection
- Shopping cart
- Checkout process

## 4. Testing Types
- Functional Testing
- Positive Testing
- Negative Testing
- Regression Testing

## 5. Testing Approach
Testing will initially be performed manually. Each test case will include steps, expected results, actual results and execution status.

In Progress — Test planning phase.
